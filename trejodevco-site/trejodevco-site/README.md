# trejodevco.com

The website for Trejo DevCo LLC and Tee Town: Golf Course Builder.
Plain HTML, CSS and a little JavaScript. No build step: edit any file here in GitHub's web editor and the site updates in a minute or two.

## Where things are
| Page | File |
|---|---|
| Home (Tee Town) | `index.html` |
| Support and FAQ | `support/index.html` |
| Delete your account | `delete-account/index.html` |
| Privacy policy | `privacy.html` (legal text: change only with legal advice) |
| Terms of use (DRAFT) | `terms/index.html` |
| Press kit | `press/index.html` |
| Creator Program | `creators/index.html` |
| About | `about/index.html` |
| Not-found page | `404.html` |

- Colors, fonts and spacing: the top of `assets/css/site.css`.
- Images: `assets/img/` (each image has a `.webp` and a `.png`; replace both).
- Store badges: `assets/badges/app-store.svg` and `assets/badges/google-play.svg` (use the official files).
- Press downloads: `assets/press/`.
- The header and footer are repeated in each page. If you change a link there, change it in every page.

## Do not delete
- `CNAME` (connects trejodevco.com)
- `googleedf3dff861f6c5ba.html` (Google Search Console verification)
- `privacy.html` and `delete-account/` (registered with Apple and Google)
